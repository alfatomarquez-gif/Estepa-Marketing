# Estepa-Marketing 🚀

Plataforma todo-en-uno de marketing digital con IA avanzada para agencias de marketing, empresas de publicidad y consultores digitales.

## 🌟 Acerca de

Estepa Marketing es una solución completa que permite a las agencias gestionar múltiples empresas cliente desde un solo lugar, con automatización inteligente de publicaciones en redes sociales, generación de contenido con IA, y comunicación multicanal integrada.

## 📋 Características de la Landing Page

- **Diseño Responsive**: Funciona perfectamente en dispositivos móviles, tablets y desktop
- **UI/UX Moderna**: Interfaz atractiva con gradientes, animaciones y efectos hover
- **Navegación Intuitiva**: Menú sticky con smooth scroll y navegación activa
- **Secciones Completas**:
  - Hero con CTAs prominentes
  - 8 funcionalidades principales
  - Beneficios competitivos
  - Casos de uso detallados
  - Testimonios de clientes
  - FAQ con acordeón interactivo
  - Formulario de contacto validado
  - Footer completo con enlaces

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica y accesible
- **CSS3**: Estilos modernos con:
  - Variables CSS para fácil personalización
  - Flexbox y CSS Grid para layouts
  - Animaciones y transiciones suaves
  - Diseño mobile-first responsive
- **JavaScript (Vanilla)**: Funcionalidad interactiva sin frameworks
  - Menú móvil toggle
  - Smooth scroll navigation
  - FAQ accordion
  - Validación de formularios
  - Efectos scroll (header, back-to-top, fade-in)
  - Active navigation highlighting

## 🚀 Cómo Visualizar

1. Clona o descarga este repositorio
2. Abre el archivo `index.html` en tu navegador web favorito
3. O usa un servidor local:
   ```bash
   # Con Python 3
   python -m http.server 8000
   
   # Con Node.js (npx)
   npx serve
   ```
4. Navega a `http://localhost:8000` en tu navegador

## ✨ Funcionalidades Destacadas

### Navegación
- Menú sticky que se mantiene visible al hacer scroll
- Menú hamburguesa responsive para móviles
- Smooth scroll a secciones internas
- Indicador de sección activa

### Interactividad
- FAQ accordion con animación suave
- Formulario de contacto con validación en tiempo real
- Botón "Volver arriba" que aparece al hacer scroll
- Animaciones fade-in en elementos al hacer scroll

### Responsive Design
- Mobile-first approach
- Breakpoints optimizados (mobile < 640px, tablet 640-1024px, desktop > 1024px)
- Grid adaptable según dispositivo
- Menú móvil con overlay
